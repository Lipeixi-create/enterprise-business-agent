## 2. 计数口径

1. “真实执行”只认归档 `records[]` 中存在 `model_calls > 0`、`llm_model`、`llm_tokens` 或超时状态的记录；check-only、假客户端、离线回放、历史摘要不计。
2. “运行当时通过”取归档生成时的 `passed` 字段；“当前评测器离线重放”用当前 `relations.py`、`evaluation.py` 对归档答案与 `tool_messages` 重新计算关系、数字溯源、数字准确性与运行时数字核对，工具链/任务完成/证据充分性/引用有效性沿用归档字段；重放不产生模型调用，也不改变真实通过数的含义。
3. 超时记录属于“已执行但失败”，不属于“未执行”。
4. 26 个 `live-*` 只有 check-only，没有 Phase 7 归档，不能计入 Phase 7 真实通过；更早的 Phase 4.5 真实记录也不能替代 Phase 7 记录。
5. 6 条历史 `phase7-*` 记录来自 `phase7_eval.first_round.json`，使用 prompt `phase5-2026-10-31.1`，本轮没有重跑；其归档没有 `tool_messages`，离线重放只能核对其存储字段与答案数字，不能重算关系断言。
6. 归档中 `api_key_configured=true` 只表示已配置，不记录任何密钥；本报告未打印任何 API Key、数据库密码或完整连接串。
